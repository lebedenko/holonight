# Directional PNG encoding rollout

The approved rollout promotes the private directional-variation selector into
[Thumbnails](../../holonight-thumbnails/docs/sdd/shared-thumbnail-cache/README.md).
The [accepted rerun](preview-cache-complexity-encoding-rerun.md) remains the startup
selection evidence: both p95 gains exceed 5 ms and both medians improve. No performance
trial is repeated. Historical qualification remains **78/80** and earlier Deferred
results and sealed attempts remain unchanged.

The provider keeps its synchronous store, default writer fallback, metadata, color,
private permissions, cancellation and atomic publication. Public headers, package
interfaces and cache formats are unchanged. Existing entries need no invalidation.

The six-component dependency order is Thumbnails, File Browser, Settings, Viewer,
Files and the portal. Consumer sources use installed revisions, including portal
`d44d9802c721f4a34e86576d3d246f4142290871`; the newer portal checkout remains untouched.
Host Release builds use four jobs and explicit installed development packages.
The rollout excludes publication, umbrella pin advancement and MIME-default extension.
A subsequent user request authorized local commits of the implementation and this note.
The provider implementation is committed as `e3f290d`; the umbrella pin remains unchanged.

## Rollout addendum

inputs match production classifications and selected writer behavior. Focused detector
and store tests pass, followed by all five provider CTest checks, including both

existing installer interfaces in an isolated source workspace. A stale user-local

including both installed-package checks. File Browser Core, Quick, QML, Preview and

chooser/wallpaper-model checks passed, as did Viewer thumbnail/cache checks, Files

The retained explicit 65-case inventory ran twice in independent private contexts
against the newly installed development prefix: **130/130 case executions**, with

than a control/candidate performance comparison. A missing required invocation marker

Targeted activation completed after the user confirmed it was safe. No affected

Final cleanup removed only the empty owned test-runtime generation directory after
