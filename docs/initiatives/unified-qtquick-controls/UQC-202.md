# UQC-202: Installer dependency capabilities

Date: 2026-09-09
Baseline: `4c38804f142486b23dc20b81f6a0fa78e5530421`

Extract command/package/compiler dependency checks from `scripts/install.sh`
into a sourceable shell helper. Remove only `qt6-wayland` from mandatory package
names. Preserve distribution, compiler, account, gitlink and all other package
checks and the installer CLI/--check behavior.

A temporary CMake configure probe requires Qt >= 6.11, WaylandClient and
Qt6WaylandScannerTools >= 6.11, matching the pinned provider. Accept merged and
standalone packaging. Preserve CMake diagnostics and report the required missing
capability without automatically prescribing qt6-wayland. Clean probe files on
exit; no installation, package transaction or persistent staging is involved.

Python standard-library regression fixtures use controlled PATH, package-manager
and CMake responses for both packaging layouts, missing capabilities, incompatible
Qt, configure failure, and unrelated missing commands/packages. Assert read-only
package queries and temporary cleanup. Expose the suite via Task and a lightweight
umbrella CI job. Run syntax, REUSE, whitespace, fixtures and real installer --check.
