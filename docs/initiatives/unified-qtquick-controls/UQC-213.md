## Demonstrated boundary

verified Batch 4 prefix, supplies `WaylandLayerSurfaceBackend::applyConfigureSize`.
It copies protocol configure dimensions directly into Qt window dimensions.

The reduced-client measurements and their limits are recorded once in
[FINDINGS.md](FINDINGS.md#batch-6-investigation--2026-09-15). The mismatch appears
without shell composition; historical Hyprland jitter remains unconfirmed.

## Proposed work

- Reproduce with an installed reduced client and real shell under isolated
  Hyprland, retaining output scale 1 and fixed output dimensions/service state.
- Settle the coordinate contract for `LayerSurfaceSpec`, configure sizes, Qt
  window/root dimensions, margins, exclusive zones and custom input regions.
  Account for Qt scale factor independently of the output's DPR contribution.
- Add a deterministic failing provider regression, then make the smallest
  provider-owned repair. Check initial configure, later configure, zero-size
  anchored dimensions, popup geometry and both style overrides.
- Confirm the reduced-client shutdown result separately before using it as a
  lifecycle regression: it exits -11 after Qt display teardown and late context
  destruction. No teardown repair or broader diagnosis is part of Batch 6.
