This isolated experiment preserves both prior encoding attempts and all production
components. Frozen C and completed early-publication evidence are bound through
pinned seals, independent proofs and complete inventories. The completed encoding
investigation is additionally pinned by seal and independent proof.

Only one policy is eligible: default PNG for SVG, unsupported formats and dimensions
below two. Formats: RGB32, ARGB32, ARGB32 premultiplied, RGBX8888, RGBA8888,
RGBA8888 premultiplied. Let nx=min(32,w-1), ny=min(32,h-1). Sample each
x=1+floor((2i+1)(w-1)/(2nx)), y=1+floor((2j+1)(h-1)/(2ny)). Count active
32-bit pixels differing from **both** left and upper neighbors; compression 11 is
selected exactly when 4*count >= nx*ny. Scan the complete grid, ignore padding,
and check cancellation before every sampled row and before encoding. Classification
is inside every timed synchronous store. Diagnostic classification, typed requests
and readback are outside. Frozen C supplies metadata, permissions, cancellation,
atomic commit and synchronous publication behavior.

and adjacent independent record are preserved. Numerical eligibility did not satisfy
